Duet 1.0.2 is a fix-only patch: themes actually apply now, and self-signed/invalid TLS certificates in a browser Portal no longer dead-end.

## Fixed
- **Light/Dark theme actually applies.** A custom GTK theme (`~/.config/gtk-4.0/gtk.css`, `GTK_THEME`) loads at user priority and redefined libadwaita's colors out from under Duet's own setting, so switching to Light or Dark often changed nothing visible. Light and Dark now also load Duet's own palettes just above user priority; Follow System is unaffected.
- **Self-signed/invalid TLS certificates no longer dead-end a Portal.** Visiting an HTTPS site with a certificate WebKit can't verify (routinely a local dev server) used to fail outright with "Unacceptable TLS certificate" and no way forward. Duet now asks whether to trust it; approving registers the exception for that one site only, scoped to that portal's own session — never a blanket "ignore all certificate errors," and never something an agent can trigger or answer on your behalf.

## Install
Requires GTK4, libadwaita, VTE (GTK4), GtkSourceView 5 and WebKitGTK 6.0, plus `git`. On Arch:

```sh
sudo pacman -S gtk4 libadwaita vte4 gtksourceview5 webkitgtk-6.0 git
tar xzf duet-v1.0.2-x86_64-linux.tar.gz
cd duet-v1.0.2-x86_64-linux && ./install.sh
```

Upgrading from 1.0.1 (or 1.0.0) needs no migration: your workspaces load as they are.
