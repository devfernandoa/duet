Duet 1.0.1 adds a logo and launcher integration, a theme switch, per-workspace project folders, and lets agents read your drawings.

## New
- **App icon and launcher entry.** Duet has a logo. `install.sh` adds Duet to your app launcher (GNOME, KDE, rofi/wofi/fuzzel, …) for your user, no root needed. `./install.sh --uninstall` removes it again.
- **Theme option.** ⋯ → Appearance → Follow System, Light or Dark. It applies immediately and is remembered.
- **A project folder per workspace.** Creating a workspace asks for its folder. You can change it at any time: click the folder under the title, use ⋯ → Workspace Folder…, or use the folder button in the workspace list. File trees, the editor, `@file:` references, Git and new terminals all follow it. Previously every new workspace silently used the directory Duet was launched from, usually your home.
- **Agents can read drawings.** Connect a drawing to an agent's terminal, and `duetctl drawing read <id>` renders it to a PNG plus a list of its strokes. The agent can open the PNG to see your sketch. Connected drawings also appear in `duetctl whoami`.

## Fixed
- Agent terminals always find `duetctl`, even when Duet was started from a desktop launcher whose PATH lacks `~/.local/bin`.

## Install
Requires GTK4, libadwaita, VTE (GTK4), GtkSourceView 5 and WebKitGTK 6.0, plus `git`. On Arch:

```sh
sudo pacman -S gtk4 libadwaita vte4 gtksourceview5 webkitgtk-6.0 git
tar xzf duet-v1.0.1-x86_64-linux.tar.gz
cd duet-v1.0.1-x86_64-linux && ./install.sh
```

Upgrading from 1.0.0 needs no migration: your workspaces load as they are.
