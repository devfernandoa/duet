Duet 1.0 runs AI coding agents (Claude Code, Codex, OpenCode, a shell, or any command) side by side on a persistent, infinite canvas. Agents can message each other, share notes, files and browser portals, and use your repository's Git, all through the same services as the GUI.

## What's in 1.0
- **Workspaces**: persistent canvases with their own project folder. Background workspaces keep their processes running, and you switch with Ctrl+1…9.
- **Agents**:
  - Claude, Codex, OpenCode, Shell or a custom command, each in a real terminal;
  - roles, including a manager role that can recruit agents;
  - isolated Claude accounts and Codex homes;
  - handoff between agents;
  - activity status.
- **Orchestration**: connect cards to grant capabilities, including agent-to-agent messaging. Agents use `duetctl` and an installed `duet` skill.
- **Notes**: Markdown with Edit, Preview and Split. Agents can read and write them, and they can be backed by a file with conflict-safe sync.
- **`@` references**: `@agent`, `@note`, `@file:path#L10-20`, `@diff:path`, `@portal:name`, resolved deterministically by `duetctl resolve`.
- **Files**:
  - file tree with Git markers, fuzzy and content search;
  - GtkSourceView editor;
  - drag files onto the canvas.
- **Git**:
  - header status (`main ↑2 ↓1 •3`);
  - stage, unstage and stage-all;
  - commit, diff, branches (switch and create), fetch;
  - fast-forward-only pull;
  - push, which never forces and publishes a new branch only after you confirm.

  The CLI has the same operations.
- **Browser portals**: embedded WebKit with isolated profiles. Connected agents can navigate, read, click, type and take screenshots. Dev-server URLs are offered.
- **Canvas**:
  - pan and zoom, selection, marquee, align/distribute, undo/redo;
  - **group sections** that sit behind your cards;
  - **drawings** for quick sketches.
- **Clean header**: workspace, Git, **+ Add** and **⋯ More**. Ctrl+? lists every shortcut.

## Install
Requires GTK4, libadwaita, VTE (GTK4), GtkSourceView 5 and WebKitGTK 6.0 (see the README), plus `git`.

```sh
tar xzf duet-v1.0.0-x86_64-linux.tar.gz
cp duet-v1.0.0-x86_64-linux/{duet,duetctl} ~/.local/bin/
```

Or build from source: `cargo install --path . --root ~/.local`.

## Upgrading
Your workspaces migrate automatically (store schema 8). Older placeholder Group and Drawing cards load as real ones. An older Duet will refuse, rather than damage, a file saved by 1.0.

## Not in 1.0
Chat views, floors (git-isolated parallel work), reusable arrangements, a command palette, routines, SSH/Docker environments and remote control are planned for after 1.0. The README's *Known limitations* section lists the current gaps.
